# Advanced Algorithmic Techniques (AAT) Lab Practicals

This repository contains a comprehensive collection of algorithmic solutions implemented as part of the **Advanced Algorithmic Techniques** curriculum. The implementations cover various paradigms, from fundamental recursive strategies to advanced optimization techniques like Branch and Bound.

---

## 📂 Curriculum Overview

The following table outlines the practicals implemented in this repository, categorized by algorithmic design strategy.

| Practical No. | Practical Title | Algorithms / Problems Covered |
| :--- | :--- |  :--- |
| **01** | **Recursive Approach** | Factorial Computation, Tower of Hanoi |
| **02** | **Non-Recursive (Iterative)** | Bubble Sort, Insertion Sort, Selection Sort |
| **03** | **Divide & Conquer** | Binary Search, Merge Sort, Quick Sort |
| **04** | **Greedy Method** | Fractional Knapsack, Activity Selection, Job Sequencing |
| **05** | **Dynamic Programming** |  0/1 Knapsack, Coin Change, Weighted Job Scheduling |
| **06** | **Graph / Path Problem** | Bellman-Ford, Floyd-Warshall, Traveling Salesman (TSP) |
| **07** | **Brute Force Method** | String Matching, Subset Sum, 8-Queens Problem |
| **08** | **Backtracking Method** |  N-Queens, Graph Coloring, Hamiltonian Cycle |
| **09** | **Branch and Bound I** |  LIFO Node Selection (Stack), FIFO Node Selection (Queue) |
| **10** | **Branch and Bound II** |  0/1 Knapsack (FIFO & LC), TSP using LC Branch and Bound |
